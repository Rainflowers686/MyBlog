# Security

MyBlog is a course project for local study. Its account, rich-text and file
upload features need a deployment review before use with real users or
internet-facing data.

The current `django-ckeditor` dependency bundles CKEditor 4.22.1 and reports
`ckeditor.W001` for its unsupported editor with known security issues. This
configuration cleanup does not replace the editor or establish production
readiness. See the [upstream support notice](https://ckeditor.com/ckeditor-4-support/).

## Configuration

Provide a fresh `DJANGO_SECRET_KEY` and a database password through process
environment variables. Startup fails when required values are missing.
`DJANGO_DEBUG` defaults to off. `.env.example` is a reference and contains no
working credentials; do not commit a filled-in copy.

Mail defaults to the console backend. Configure a real mail backend before
using password resets with real users. `MYBLOG_DEMO_PASSWORD_RESET` defaults
to off and requires `DJANGO_DEBUG=1` as a second condition. Enabling it exposes
a reset link in the browser and is suitable only for an isolated demonstration
with disposable accounts.

New users made by `populate_db.py` have unusable passwords. Existing
demonstration accounts are unchanged: disable them or set individual passwords
before using an old database with real users.

## Previously committed values

Older source contained a development secret key and a nonempty database
password. The repository also tracked generated bytecode, which can retain
older configuration. Rotate either value if it was used outside
an isolated, disposable environment, and replace it wherever it was reused.
The previous SMTP username and password fields were empty.

Changing the current files and deleting generated bytecode does not invalidate
an old credential or remove earlier Git objects. This change does not rewrite
repository history. Password reset tokens and sessions issued with an old
secret may become invalid after rotation.

## Reporting

Use **Report a vulnerability** on the repository's Security tab if GitHub
offers that private form. Otherwise, open an issue requesting a private
contact without including credentials, personal data, exploit details or a
database dump. Wait for a private channel before sending sensitive material.

Include the affected commit, environment and a reproduction with synthetic
accounts and data. The project does not promise a response time or support
window for historical course versions.
